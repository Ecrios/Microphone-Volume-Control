Продвинутый скрипт для удобного управления громкостью и включением/выключением микрофона, написанный на **AutoHotkey v2**. Позволяет регулировать звук колесиком мыши в углу экрана, моментально задавать точную громкость или плавно изменять ее с помощью глобальных горячих клавиш.

## ✨ Основные возможности

- **📐 Активация по углу экрана:** Быстрый доступ к управлению громкостью при наведении курсора в выбранный угол экрана.
- **⚡ Точные горячие клавиши:** Мгновенный выбор уровня громкости (от 10% до 100%) комбинацией `Right Alt` + `1..0`.
- **🌊 Плавное нарастание / затухание:** Плавная регулировка громкости за 1.5 секунды нажатием горячих клавиш.
- **🖥️ Красивый OSD-индикатор:** Всплывающий оверлей с отображением процента громкости, прогресс-бара и состояния:
  - 🟢 **Зеленый индикатор:** Микрофон активен.
  - 🔴 **Красный индикатор:** Микрофон выключен (Mute).
- **🧠 Умное авто-скрытие OSD:** Индикатор автоматически исчезает при уходе из угла, завершении плавного затухания или через 1.5 секунды бездействия.
- **⚙️ Гибкое меню в Трее:** Выбор конкретного микрофона из списка, сменяемые углы активации и настройка шага регулировки.
- **💾 Сохранение настроек:** Все конфигурации автоматически сохраняются в файл `settings.ini`.

## ⌨️ Горячие клавиши и управление

### 1. Управление в углу экрана
*(Работает только когда курсор мыши находится в активном углу)*

| Сочетание | Действие |
| :--- | :--- |
| `Колесико вверх` | Увеличить громкость на заданный шаг |
| `Колесико вниз` | Уменьшить громкость на заданный шаг |
| `Клик колесиком` | Включить / Выключить микрофон (Mute) |

---

### 2. Глобальные горячие клавиши (Строго Правый Alt)

#### 🎯 Мгновенный выбор громкости
Быстрая установка точного значения громкости из любого приложения:

| Горячая клавиша | Действие |
| :--- | :--- |
| `Right Alt` + `1` … `9` | Мгновенно установить **10% … 90%** |
| `Right Alt` + `0` | Мгновенно установить **100%** |

#### 🌊 Плавное изменение громкости (1.5 секунды)
Плавный переход от текущего уровня до целевого за 1000 мс:

| Горячая клавиша | Целевая громкость | Физическая клавиша |
| :--- | :---: | :--- |
| `Right Alt` + `,` | **10%** | Клавиша `Б` / Кома |
| `Right Alt` + `.` | **25%** | Клавиша `Ю` / Точка |
| `Right Alt` + `/` | **75%** | Клавиша `.` (в рус. раскладке) / Слэш |

## ⚙️ Настройки в Трее

Нажмите правой кнопкой мыши по иконке программы в **системном трее (возле часов)**:
- **Выбор микрофона:** Переключение между режимом `Автоматически` и конкретным устройством.
- **Активный угол:** Верхний левый, Верхний правый, Нижний левый, Нижний правый.
- **Шаг изменения:** Выбор шага регулировки колесиком (от 5% до 50%).
- **Обновить список устройств:** Сканирование новых подключенных аудиоустройств без перезапуска программы.

## 📥 Установка и запуск

### Требования
1. Установленный **[AutoHotkey v2.0](https://www.autohotkey.com/)** или новее.

### Запуск
1. Скачайте файлы репозитория.
2. Запустите файл `main.ahk` двойным кликом.
3. Скрипт автоматически создаст файл `settings.ini` рядом с собой для сохранения настроек.

---

## 📁 Структура файлов

- `main.ahk` — Основной исходный код программы.
- `settings.ini` — Пользовательский файл настроек (генерируется автоматически).
